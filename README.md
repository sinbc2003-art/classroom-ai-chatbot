# 🎓 수업용 AI 챗봇 플랫폼 (로컬 서버)

교실 환경에서 교사의 노트북을 로컬 서버로 구동하여 **최대 30명 이상의 학생**이 동시 접속하여 OpenAI 기반 AI와 대화할 수 있는 교실 특화 웹 애플리케이션입니다.

---

## 🌟 핵심 특징

1. **원클릭 로컬 서버 구동 (`run.bat`)**
   - 별도의 복잡한 설치 과정 없이 `run.bat` 더블 클릭만으로 서버 실행 및 브라우저가 자동 실행됩니다.
   - 교실 Wi-Fi 망 내에 연결된 학생 기기(스마트폰, 태블릿, 노트북)에서 자유롭게 접속 가능합니다.

2. **편리한 학생 입장 (비밀번호 없음)**
   - 학생들은 첫 접속 시 **학번/이름**만 입력하면 즉시 대화를 시작할 수 있어 수업 시간을 절약합니다.
   - 기기별 세션이 기억되며, 필요 시 언제든지 **[+ 새 대화]** 버튼으로 새로운 질문을 시작할 수 있습니다.

3. **관리자 센터 (`/admin`) & 모델 선택 서빙**
   - **기본 비밀번호:** `1234` (관리자 화면에서 변경 가능)
   - 관리자 화면에서 OpenAI API 키를 입력하면 **보유 중인 모든 OpenAI 모델(`gpt-4o`, `gpt-4o-mini`, `o3-mini` 등)을 실시간으로 호출**합니다.
   - 관리자가 대표 모델을 선택하면 **모든 학생에게 해당 모델이 일괄 즉시 적용**됩니다.

4. **실시간 학생 대화 내역 저장 & CSV 다운로드**
   - 모든 학생의 발화 및 AI 응답이 SQLite DB(동시성 처리에 강력한 WAL 모드 적용)에 영구 저장됩니다.
   - 학생별/전체 대화 내역을 **엑셀(Excel) 한글 깨짐이 없는 UTF-8 BOM CSV 파일**로 즉시 다운로드할 수 있어 수업 평가 및 피드백에 활용할 수 있습니다.

5. **수식(MathJax/LaTeX) & 스트리밍 & 마크다운 완벽 지원**
   - **수식 렌더링:** `$인라인수식$` 및 `$$블록수식$$`, `\(...\)`, `\[...\]` 문법을 지원하여 수학/물리 공식을 미려하게 표시합니다.
   - **SSE 실시간 스트리밍:** 타자 치듯 부드럽게 생성되는 AI 답변과 자동 스크롤을 제공합니다.
   - **코드 하이라이팅 & 복사:** 파이썬, 자바 등 소스 코드 구문 강조 및 원클릭 복사 버튼을 제공합니다.

6. **교실 Wi-Fi 접속 안내 (QR 코드 지원)**
   - 관리자 페이지 첫 화면에 **노트북의 Wi-Fi IP 주소**와 **학생 접속용 QR 코드**가 자동으로 생성됩니다.
   - 학생들은 스마트폰/태블릿 카메라로 화면의 QR 코드만 스캔하면 즉시 접속됩니다.

## 🚀 빠른 시작 방법

### 방법 1. 원클릭 실행 (추천)
`run.bat` 파일을 더블 클릭하여 실행합니다.

### 방법 2. 콘솔에서 직접 실행
```powershell
# 1. 의존성 설치
python -m pip install -r requirements.txt

# 2. 서버 실행 (0.0.0.0 바인딩으로 교실 내 외부 기기 접속 허용)
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

---

## 📱 접속 주소 안내

- **선생님 노트북 (로컬):** `http://localhost:8000`
- **학생들 접속 주소 (같은 Wi-Fi):** `http://<선생님노트북IP>:8000`
- **관리자 센터:** `http://localhost:8000/admin` (초기 비밀번호: `1234`)

> 💡 관리자 센터(`http://localhost:8000/admin`)에 들어가시면 화면에 학생들에게 보여줄 수 있는 **접속 URL과 QR 코드**가 표시됩니다.

## 🛠️ 관리자 센터 주요 기능

1. **OpenAI API 키 설정 & 모델 조회:**
   - OpenAI API 키(`sk-...`)를 입력하고 **[API 키 저장 및 모델 목록 조회]**를 클릭합니다.
   - 계정에서 사용 가능한 전체 모델 목록이 실시간 로드되며, 드롭다운에서 학생들에게 서빙할 모델을 지정할 수 있습니다.
2. **수업용 시스템 프롬프트(AI 지침) 템플릿:**
   - 📐 **수학 탐구 튜터:** 공식 유도 및 단계별 발문 유도
   - 🏛️ **소크라테스 질문형:** 정답을 바로 주지 않고 질문을 통한 사고 확장
   - 🔬 **과학 탐구 멘토:** 가설 설정과 원리 이해 지원
   - 💻 **코딩/알고리즘 코치:** 오류 원인과 디버깅 흐름 안내
   - ✨ **일반 친절한 조교:** 다정하고 친절한 일반 학습 지원
3. **학생 대화 모니터링:**
   - 학생 목록 실시간 조회 (이름, 누적 대화 수, 마지막 활동 시간)
   - 학생 이름 클릭 시 **전체 대화 타임라인 모달 열람**
   - **전체 대화 CSV 다운로드** (학번/이름, 세션, 발화자, 내용, 사용 모델, 시간 기록)

## 📂 프로젝트 구조

```
안티그래비티 텥스트/
├── run.bat               # Windows 원클릭 서버 실행 배치 파일
├── requirements.txt      # 파이썬 의존 라이브러리 목록
├── main.py               # FastAPI 서버, SSE 스트리밍, 관리자 API
├── database.py           # SQLite DB 관리 (WAL 모드로 30명 동시성 보장)
├── test_server.py        # 자동화 테스트 스위트
├── data/
│   └── classroom_chat.db # 학생 정보, 대화 로그, 설정 저장 DB
└── static/
    ├── index.html        # 학생용 웹앱 화면
    ├── admin.html        # 관리자 센터 화면 (QR코드, 모델관리, CSV)
    ├── css/
    │   └── style.css     # 수식/마크다운/채팅 버블 스타일시트
    └── js/
        ├── chat.js       # 학생 클라이언트 (SSE, MathJax 렌더링)
        └── admin.js      # 관리자 클라이언트 (모델 조회, QR 생성, CSV)
```
